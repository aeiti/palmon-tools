# Changelog

User-facing changes to Palmon Tools.

For full per-release notes including all merged commits, see
[GitHub Releases](https://github.com/aeiti/palmon-tools/releases) —
those are auto-generated on every push to `main` and capture the
fine-grained per-deploy history.

## 2026-06

### Added
- **Notes** tool — per-profile free-form journal entries,
  categorized (player / event / item / palmon / building / other)
  with an optional link to a Palmon species or building.
- L30 skill data for 5 new mythical Palmon: Hexkit, Zapantis,
  Embergeist, Thundertooth, Mammolith. Rootwarden's skill data
  also filled in.
- Search-engine indexing: per-route page titles, OpenGraph and
  Twitter card meta, canonical links, sitemap, robots.txt.

### Changed
- Resource Inventory column order — Steel now appears before
  Lumber.

## Pre-2026-06

Existing tools shipped before this changelog started:

- **Buildings** — track building level and assigned Palmon per
  slot.
- **Inventory** hub with **Other**, **Resources**, **Speedups**
  sub-pages.
- **Palmon** — roster of your Palmon: level, stars, squad,
  equipment, skills, traits.
- **Squads** — see each squad and the Palmon assigned to it.
- **Dashboard** — landing page with a tile per tool.
- **About** — what this is, disclaimer, feedback link.

Plus a catalog of 50+ Palmon species with skill data for many,
per-profile state with localStorage persistence, and
backup/restore.

See the [GitHub Releases page](https://github.com/aeiti/palmon-tools/releases)
for the full release history.
